Four locations on disk, one job each: the source repository (edit here), a deployed runtime copy (daemons run from here, never edited by hand), binaries, and config plus the semantic memory store. A deploy script runs the test suite, mirrors source to runtime, and verifies the entrypoints below.

## Daemons
